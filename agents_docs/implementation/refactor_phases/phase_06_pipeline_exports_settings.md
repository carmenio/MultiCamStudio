# Phase 6: Pipeline, Exports, and Settings

## Status

Pending Phase 5 acceptance. No structural changes have started.

## Frozen interfaces

Canonical session ownership, additive enrichment, ordered enabled stages, task
progress, selection reconciliation, reviewed export specifications, missing-frame
continuity, atomic finalization, synchronous compatibility routes, settings keys,
and filter/sort semantics remain unchanged. EdgeRelay index refresh remains
separate from browser playback-cache deletion.

## Intended ownership and data flow

The All page becomes a coordinator over established workflow interfaces. Export
planning and execution deepen behind the existing task and compatibility
boundaries. Shared preferences, formatting, and error parsing consolidate only
after semantic equivalence is characterized.

## Acceptance evidence required

Benchmark overview loading, dispatch, export planning, throughput, and
finalization. Verify stage ordering, additive rows, final artifact identity, and
selection behavior in automated and live flows.

## Rollback

Restore the existing coordinator and internal export/settings callers. No export
layout, task, browser-key, endpoint, or database migration is permitted.
